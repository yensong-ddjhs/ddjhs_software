前往平台

開啟康軒雲 ↗

登入方式：使用學校 Google 帳號登入。

常用操作

01｜登入平台

開啟康軒雲，依登入畫面使用學校 Google 帳號進入。

02｜電子書與教學資源

登入後，依年級、科目與版本尋找合適的電子書或教學資源；開啟方式請參考影片與實際介面。

03｜題庫與作業

依教學單元尋找題庫，確認適用年級與題目；如需派送作業，請依平台畫面選擇對象與任務設定。

04｜班級管理

查看所屬班級與名單；若需建立或調整班級，請依畫面及學校帳號權限操作。

功能名稱、班級設定及派送流程可能依平台版本或學校權限不同；請參考影片及登入後畫面。

常見問題

無法使用學校 Google 帳號登入？

確認使用學校帳號並檢查瀏覽器是否已登入其他 Google 帳號；若仍無法登入，請聯絡學校資訊人員確認帳號及授權。

找不到電子書、教材或題庫？

確認登入的是教師帳號，檢查年級、科目、版本與學校授權範圍；功能名稱依實際介面為準。

看不到班級或無法派送作業？

請先確認班級及學生名單是否完成設定、教師是否具有相應權限；若仍有問題，請洽學校資訊人員或平台客服。

前往平台

開啟康軒 KUSE AI ↗

登入方式：依學校提供的帳號資訊操作。

從教學需求開始

01｜登入並選擇工具

登入後依實際畫面選擇合適的教學工具或範本。

02｜描述需求

寫明年級、科目、單元、時間及輸出格式；若使用教材，先確認可上傳或提供的資料範圍。

03｜檢查與調整

核對生成內容，依學生程度修改，再依介面提供的方式保存或下載。

教案、試題、學習單、摘要與圖片均可作為教學應用方向；實際是否提供特定工具、圖片生成或上傳功能，請以帳號與平台畫面為準。

可複製的通用指令

將【方括號】改成自己的需求；以下為通用範例，並非特定功能按鈕。

產生教案

請協助我設計【年級】【科目】【單元】的教案，教學時間【分鐘】；請列出學習目標、教學流程、生活化活動和評量方式。

設計試題

請依據我提供的【教材內容】，為【年級】設計【題數】題【題型】，附答案及解析；未提及的內容請勿自行補充。

製作學習單

請為【年級】【科目】的【單元】製作一份學習單，包含生活情境、引導問題與參考答案，預計完成時間【分鐘】。

摘要教材

請將以下教材整理成適合【年級】閱讀的重點摘要，列出五項重點與三個複習問題：[貼上教材]。

圖片提示詞

請為【科目】【單元】撰寫一段教學圖片生成提示詞，對象是【年級】，畫面內容應包括【重點】，風格清楚易讀。

常見問題

生成內容太籠統，怎麼調整？

補上學生年級、科目、單元、教學時間、題型與輸出格式，並告訴 AI 哪些部分需要修改。

生成的教材可以直接使用嗎？

請先檢查內容正確性、版權、學生程度及課程適切性，再自行修改後使用。

找不到摘要或生成圖片的功能？

各帳號功能與權限可能不同；請以登入後實際顯示的工具為準，或向學校管理人員確認。

前往平台

開啟 Build School（ChatGPT） ↗

登入方式：依學校提供的帳號資訊操作。

基本對話與提問

01｜寫下需求

在對話框說明任務、年級、科目、主題及希望的格式。

02｜送出與追問

檢查回覆，若需修改可接著提出，例如「改成適合國中生的生活化情境」。

Agent 工作區：處理檔案

01｜開啟並上傳

點擊對話框的「Agent工作區」，在工作區上傳需要處理的檔案。

02｜輸入任務

回到對話，寫明檔名、處理方式與輸出格式，例如逐字稿、SRT 字幕、Word 或圖表。

03｜查看與下載

使用對話中提供的連結下載，或在工作區的 output 資料夾查看成果。

保存提醒：工作區檔案保留 3 天，請及時下載備份。影音轉錄建議上傳小於 100 MB 的檔案。

私人模式

多人共用平台帳號時，可點擊「私人模式」，閱讀說明後決定是否使用個人 Google 帳號登入；不需要時可選「取消／略過」。依先前提供的畫面說明，私人新對話會存入私人對話區；重要對話建議移入私人資料夾並自行備份。私人模式不同於「臨時隱藏對話」。

私人模式不代表資料一定不會送往外部服務；對話與工作區檔案的保存、同步及存取，請依學校規範與系統實際設定確認。

Build School 操作畫面

操作截圖待補

先前提供的三張操作截圖目前未能在本次工作區取得，故暫不顯示，避免誤用其他圖片。請重新上傳主對話框、Agent 工作區及私人模式畫面，即可補入。

可複製的指令範例

將【方括號】改成自己的需求或檔名。

教案設計

請幫我設計【年級】【科目】【單元】教案，時間為【分鐘】，包含學習目標、教學流程、分組活動、評量及差異化建議。

試題設計

請根據以下教材設計【題數】題適合【年級】的選擇題，每題四個選項，附答案和解析：[貼上教材]。

行政工作

請把以下會議紀錄整理成決議事項、負責人、完成期限三欄；未提及的資訊標示「待確認」：[貼上紀錄]。

影音轉錄

請將 Agent 工作區中的【檔案名稱.mp3】轉錄為繁體中文逐字稿，並整理會議重點；不清楚的部分請標示待確認。

檔案轉換

請將 Agent 工作區中的【檔案名稱.pdf】轉成 Word，完成後提供下載連結。

常見問題

找不到上傳的檔案？

確認檔案已上傳至 Agent 工作區，並請 AI 列出工作區檔案；如有多個檔案，請在指令中寫明檔名。

轉錄有錯字或辨識不清？

語音辨識可能出錯，請核對原音並修正人名、專有名詞及標點；也可以請 AI 依上下文協助校對。

如何找到完成的檔案？

使用對話中提供的下載連結，或到 Agent 工作區的 output 資料夾查看；請在保存期限內下載備份。

私人模式等於資料完全保密嗎？

不一定。資料是否經外部服務處理，以及工作區存取與保存方式，取決於實際服務、管理設定及學校規範。
